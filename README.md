# Path-find

Path-find is a scholarship discovery frontend prototype for a worldwide scholarship platform.

## Current frontend

- Responsive landing page and scholarship discovery board
- Search by scholarship, provider, field, destination, or award type
- Filters for study level, destination, fully funded, merit-based, and need-based opportunities
- Scholarship detail modal with official provider links
- Save/unsave shortlist stored in browser local storage
- Mobile navigation and reduced-motion support

## Run locally

This first version is a standalone static site. Open `index.html` in a browser, or serve the repository with any static web server.

## Important data note

Some listings are illustrative/demo entries and should not be treated as a verified live scholarship database. Always confirm current eligibility, award amounts, deadlines, and application instructions on the official provider website. A future phase can replace the demo array in `index.html` with verified data from a backend/API and add personalized matching.

## Deployment

The static frontend can be deployed to GitHub Pages, Vercel, Netlify, or another static hosting provider.
